# Malatro

A Balatro-style roguelike deckbuilder where every card is a real Polish matura math task 🃏📐

Solve the task to find out what your card is worth — knowing your hand means knowing the math!

_Note: this project was fully vibe coded just for fun. It is an unofficial fan project and is not affiliated with, endorsed by, or connected to LocalThunk or Playstack. "Balatro" is a trademark of its respective owner._

## Running locally

```bash
bun install
bun run dev
```
